# 换屏保脚本说明

## 两个脚本，选一个用

| 脚本 | 适用情况 | 特点 |
|---|---|---|
| **换屏保.bat** | ⭐ **推荐**，直接用这个 | 纯 CMD，零依赖，不会报错 |
| 换屏保_PS版.bat | 备用 | 内部生成临时 .ps1 再执行，逻辑更灵活 |

两者功能相同：备份原图 → 把你的图循环铺满所有坑位。

---

## 使用方法

1. 把 `换屏保.bat` 放到一个空文件夹里（例如桌面新建的"换屏保工具"）。
2. 双击运行。
3. 第一次运行会自动创建 `my_screensavers` 文件夹，并提示你放图片。
4. 把图片（**jpg / jpeg / png**）拖进 `my_screensavers`。
5. **回到黑窗口，按任意键** —— 它会自动继续，不用重开脚本。
6. 完成后重启希沃管家，或重新触发一次屏保即可看到效果。

> 建议图片用 **1920×1080（16:9）**，否则全屏可能变形或留黑边。

## 为什么之前的版本会报错？

之前那版在 `.bat` 里用 `^\` 续行内联了多行 PowerShell：

```bat
powershell -Command ^
  "$sourceFiles = Get-ChildItem ... ;" ^
  "foreach ($t in $targetFiles) { $s = $sourceFiles[$i % $sourceFiles.Count]; ... }"
```

问题出在 **CMD 会先于 PowerShell 解析这一行**：

| 报错 | 原因 |
|---|---|
| `Missing ']' after array index expression` | `$i % $sourceFiles.Count` 里的 `%` 被 CMD 当作**环境变量起始符**，把后面的内容吃掉/改写了 |
| `The string is missing the terminator` | `^` 续行 + 双引号嵌套，CMD 的引号配对规则与 PS 不同，字符串被截断 |
| `Unexpected token '$(...` | `$(Get-Date ...)` 在残缺引号下传给 PS，解析失败 |

**换屏保.bat 完全不调用 PowerShell**，所以这些报错从根上消失。

## 安全性

- **自动备份**：每次运行前，原图会完整备份到
  `%APPDATA%\seewo\SeewoAbility\screen_saver_backup_日期_时间\`
- **可还原**：把备份文件夹里的文件拷回 `screen_saver` 即可。
- **只动图片，不改程序**：不修改希沃任何可执行文件或 `app.asar`。

> ⚠️ 这些图片是**希沃集控下发**的。如果学校后台重新推送了屏保，
> 或希沃升级，图片可能被覆盖回去 —— 重新运行一次脚本即可。
